# Shad's Work Shop — SITEMATE Project

> A personal workshop repository by **AlbertanCoder (Shad)** focused on building the **SITEMATE** project.

---

## 📋 Project Overview

**SITEMATE** is a site/project management web application designed to help teams track work sites, manage tasks, log issues, and keep documentation organised in one place.

This repository is the workspace where the SITEMATE application will be designed, built, and iterated on.

---

## 🚀 Getting Started

Once development begins, the project will be runnable with:

```bash
# Install dependencies
cd sitemate/backend
npm install

# Start the development server
npm run dev
```
